# NOTES — 教学偏好与工作笔记

## 用户偏好
- 语言：中文。所有内容为中文，妈妈版讲义要能打印、能朗读、手机能打开。
- 语气：对妈妈绝对不能像说教；对用户（我自己）的说明要直接、不绕弯。
- **课程是给妈妈看的**：核心交付物是妈妈能读的讲义。
- **我不擅表达**：所有面向妈妈的文字都要平实、短句、像"我"平时说话；不硬拗煽情。
- **交付要完整、可直接执行**：课程 = 妈妈讲义 + 我的执行手册 + 妈妈记录卡 + 结业证书，不能只有框架。

## 妈妈版讲义的三条铁律（写给未来的自己）
1. 绝不出现：心理学术语（自卑/敏感/防御/创伤/原生家庭/宣泄/疗愈…）
2. 绝不批评：元素舞、盘海英、任何她喜欢的课程或人
3. 绝不出现"你应该改变""你听我的""这是为你好"
4. 全部用"我们"，用孩子的口吻，平实、具体、允许跳过、允许暂停
5. 讲义必须是单文件自包含 HTML（发飞书链接时外部 CSS 会失效）

## 沟通雷区速记
- 任何"你应该… / 这样不对 / 为什么不…"都会触发"你在评判我"
- 顺序错=全错：先验证情绪，再谈事实
- 她要求"无条件支持"——我们支持她的感受，但不支持她的行为（借钱）
- 我话少没关系：听比说重要；短句就够（见第 2 课"内向版话术"）
