Reference · 路线图

课程路线图（阶段大纲）

从"零基础"到"能独立分析一个真实商业案例并说清它"。随学习进度实时更新。

总目标：系统掌握销售 + 市场营销，同时补齐书面表达 / 口头表达 / 谈判沟通。三线并进：通用沟通力 · 销售方法论 · 市场营销与增长。

说明：实际教学顺序由你的掌握速度动态调整——上手快就往下走，卡住就多练。每完成一课，此处会更新为 ✅ 并链接到课程。

阶段 0 · 建立坐标系

状态课收获
✅L1 商业思维全景图营销 vs 销售、价值循环、漏斗、B2B/B2C、获客渠道人找货/货找人/人传人

阶段 1 · 通用沟通力 先攻短板

状态课收获
✅L2 说服性写作 / 文案把想法写成让对方想行动的文字
◻L3 结构化口头表达30 秒说清一个产品 / 方案
◻L4 谈判与沟通基本功聆听、提问、异议处理、双赢

阶段 2 · 销售流程

状态课收获
◻L5 销售漏斗与销售流程全景线索 → 接触 → 需求 → 提案 → 成交 → 跟单
◻L6 需求挖掘：SPIN 提问法B2B 大客销售的核心
◻L7 提案、报价与成交销售里的谈判落地
◻L8 异议处理与跟单CRM 入门

阶段 3 · 市场营销与品牌

状态课收获
◻L9 市场细分 / 目标市场 / 定位 (STP)给产品找准位置
◻L10 4P 与营销组合产品 / 价格 / 渠道 / 促销
◻L11 品牌与定位：案例拆解真实公司怎么讲故事

阶段 4 · 数字营销与增长

状态课收获
◻L12 数字营销地图内容、SEO、广告、基础数据
◻L13 转化率优化与增长思维AARRR 漏斗

阶段 5 · 综合实战 / 智慧

状态课收获
◻L14+ 完整真实项目 / 案例综合拆解把全部能力串起来
◻社区 / 真实试炼wisdom（需先征得你同意加入社区）
