销售与市场营销术语表

本学习工作区的统一语言。所有课程、练习、学习记录都应遵循这里的说法。

说明：术语表随手写会失去意义——这里的每一个词，都是在课程里你已经能用对之后才收录的。所以它会随着你的学习逐步长出来，而不是一开始就塞满。下方是第 1 课《商业思维全景图》建立起来的基础词汇。

底层框架

营销 (Marketing)：
创造并引导市场对产品的需求，把"陌生人"变成"感兴趣的人"。包括广告、内容、品牌、促销等所有"吸引 + 说服"的动作。
避免：推广、打广告、营销就是发传单

销售 (Sales)：
把已经感兴趣的人转化为下单付款的客户。包括需求挖掘、演示、报价、谈判、成交、跟单。
避免：推销、卖东西、忽悠

价值循环 (Value Cycle)：
商业运转的基本闭环：创造价值 → 吸引注意（营销）→ 转化为成交（销售）→ 交付留存 → 复购推荐 → 再创造价值。营销在"注意"，销售在"成交"。
避免：赚钱流程、生意模式

销售漏斗 (Sales Funnel)：
客户从「看见」到「下单」所经过的逐步收窄的过程，越往下人数越少。典型为：关注 → 线索 → 商机 → 成交 → 复购。
避免：销售管道、转化通道

漏斗内常用词

线索 (Lead)：
对你的产品表达了初步兴趣并留下联系方式的潜在客户，还没到可成交阶段。
避免：潜在客户、名单、客源

商机 / 机会 (Opportunity)：
已进入销售跟进、有明确成交可能的客户，通常已确认需求和预算。
避免：准客户、机会单

转化率 (Conversion Rate)：
某一环节的产出的比例，如"线索 → 成交"的转化率 = 成交数 ÷ 线索数。是衡量营销/销售效率的核心数字。
避免：成功率、成交比

市场类型

B2B（企业对企业）：
客户是企业/组织，决策人常不止一个，周期长、客单价高、更看重专业与 ROI。
避免：对公、企业市场

B2C（企业对个人）：
客户是个人消费者，决策更快、更情绪化，更看重价格与便利。
避免：零售、对私

获客与渠道

获客 (Acquisition)：
把注意力变成「第一次看见你」的过程，属于漏斗最顶端露出的那一层。它决定「有没有人来」，与「来了之后信不信」的转化层是两回事。
避免：拉到客户、推广、跑量

获客引擎（人找货 / 货找人 / 人传人）：
三种不同的「让别人第一次看见你」的分发逻辑。 人找货：用户带着明确需求主动搜索（淘宝、京东）；货找人：需求潜伏、被内容 + 算法激发（抖音、小红书）；人传人：靠熟人分享 / 裂变 / 私域（微信、拼多多）。
避免：获客方式、引流手段

口碑 / 病毒渠道：
靠人与人之间的分享与转介传播，是三类渠道里流量通常最「精」、转化率最高的一种。但多数时候它建立在已有信任之上，难以凭空冷启动——口碑是「放大器」不是「启动器」。
避免：好评、转介绍、自来水

付费渠道 / 有机渠道：
获客渠道的另两类。付费渠道：花钱直接买曝光（SEM、信息流、广告赞助、DOU+/千川）；有机渠道：不花钱、靠内容与搜索的自然流量增长（SEO、内容营销、社区、应用商店优化）。
避免：投广告 / 免费渠道（措辞过粗）

文案与写作

文案 (Copywriting)：
用文字推动读者採取行动的写作，出现在漏斗「吸引注意（营销）」层。衡量标准是读者有没有照做（点开 / 下单 / 留资），而非文笔。
避免：文采、广告语、文案＝写作文

功能 vs 好处 (Feature vs Benefit)：
功能是产品做了什么，好处是读者得到了什么。读者只买好处；写时按「功能 → 对你来说就是……（好处）」翻译。
避免：卖点、参数、这产品很强

行动指令 (CTA)：
Call to Action，一句话告诉读者现在该做什么，要清晰、具体、低门槛（「点击免费试用」「回复 1 领取」）。
避免：欢迎选购、敬请关注、行动号召

AIDA：
经典文案结构：Attention 抓注意 → Interest 引起兴趣 → Desire 唤起渴望 → Action 推动行动。
避免：写作公式、四段式
