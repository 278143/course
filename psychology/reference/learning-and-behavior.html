学习与行为改变速查

配套课程：第 3 课 · 打印后可贴在书桌前

两种学习形式

经典条件反射操作性条件反射
提出者巴甫洛夫斯金纳
机制刺激-刺激配对 → 自动联想行为-后果 → 行为改变
学习方式被动、自动、不涉意志主动操作、有意图
例子铃声→流口水；提示音→心跳点赞→更爱发；超速罚款→减速

操作性四象限

给予刺激移除刺激
行为增加正强化（给愉快刺激）负强化（移除厌恶刺激）
行为减少正惩罚（给厌恶刺激）负惩罚（移除愉快事物）

⚠️ 负强化增加行为，惩罚减少行为——两者方向相反，是最常见的混淆点。

斯金纳箱与强化程序表

斯金纳箱（操作条件反射箱）：斯金纳设计的实验箱——老鼠压杠杆 → 掉出食物丸。用于把"行为 → 后果 → 行为改变"放进可控环境精确研究。配套读物：OpenStax Psychology 2e · 6.3。

发放方式效果现实例子
连续强化学得快，停奖后退消也快每次发帖都有人赞
部分强化学得稍慢，但极难消退赞时有时无，反而更惦记
变比率强化（老虎机）部分强化里最难戒：中奖间隔完全随机老虎机压杆，"也许下一把就中"

老虎机原理：时灵时不灵的奖励最难消退——期待始终在线。撕嘴皮/抠结痂的满足感同样"时灵时不灵"，故按老虎机规则被强化，难戒是机制使然，不是意志力问题。

消退与恢复

  • 消退：后果不再出现 → 行为逐渐减少。
  • 自发性恢复：消退后行为突然重现——正常现象，不是失败。
  • 部分强化效应：偶尔强化最难消退（老虎机原理）。

为什么惩罚常常无效

  • 只能暂时压制，不教新行为；
  • 延迟惩罚几乎无效；
  • 引发回避与隐瞒；
  • 自我批评可能形成负强化循环。

行为改变配方：前因 → 行为 → 后果

  1. 削弱强化：改变后果，降低即时满足（非惩罚）。
  2. 替代反应：同一情境插入不伤身的竞争行为（HRT 核心）。
  3. 环境设计：控制前因，减少触发。
  4. 自我监控：记录行为本身就有减少效果，且能诊断强化类型。
