课程 0001 · 法律体系入门

中国法律体系全景图：一张地图看懂你的权利在哪里

⏱ 预计 30 分钟 · 零基础友好 · 无需任何法律背景

本课目标 学完本课，你将能：① 说出法律位阶的层级与"上位法优于下位法"；② 说出七大部门法的名称；③ 把"欠薪、押金、假货、被盗"四个生活场景对应到正确的部门法；④ 会用国家法律法规数据库查法条。

1为什么先学"地图"？

很多初学者以为学法律就是"背法条"。但中国法律不是一部"万能法典"，而是一套由不同层级、不同部门组成的体系——这正是"律法"二字的含义：有"律"（规则），更有"法"（体系）。

你生活中的每一个具体问题，几乎都能在这张地图上找到它的"归属地"：

  • 老板拖欠工资 → 归劳动法管
  • 房东不退押金 → 归民法（民法典）管
  • 买到假货 → 归消费者保护管
  • 手机被偷 → 归刑法管

先学会看地图，你就知道：遇到问题该翻哪本书、找哪个部门、走哪条路。这就是本课的核心。

2法律位阶：法律的"金字塔"

中国的法律文件有严格的效力等级（位阶）。位置越高，效力越强；低层级的文件不得与高层级冲突。

宪法根本法 · 最高效力
法律全国人大及其常委会制定
行政法规国务院制定
地方性法规地方人大及其常委会制定
规章等部门规章 / 地方政府规章
层级由谁制定常见例子
宪法全国人民代表大会1982 年宪法（2018 年修正文本为现行文本）
法律全国人大及其常委会《民法典》《刑法》《劳动合同法》
行政法规国务院《工伤保险条例》《劳动合同法实施条例》
地方性法规省、设区的市人大及其常委会各省《物业管理条例》
规章国务院部门 / 地方政府住建部《商品房屋租赁管理办法》
补充 司法解释（最高人民法院、最高人民检察院发布）不在立法法规定的位阶里，但它指导法院裁判，实践中非常重要。学习时记住：司法解释效力低于法律，且必须与法律一致。

冲突了怎么办？三大适用规则

当不同文件对同一问题规定不一致时，按这三个规则决定适用谁（这也是法院判案的基本方法）：

  • 上位法优于下位法——宪法＞法律＞行政法规＞地方性法规，低层级让位于高层级；
  • 特别法优于一般法——比如《消费者权益保护法》与《民法典》都有规定时，消费者问题优先适用《消法》；
  • 新法优于旧法——同一机关制定的文件，后颁布的优先。

法律冲突时如何适用，是全国人大常委会的官方普法重点。详见：中国人大网 · 发生"法律冲突"时如何适用法律？

3七大部门法：法律世界的"七栋楼"

按全国人大常委会的官方划分，中国特色社会主义法律体系分为七个法律部门。记住这七个名字，你就拿到了地图的骨架：

#部门法管什么代表法律
1宪法及宪法相关法国家根本制度、公民基本权利宪法、立法法、选举法
2民法商法平等主体之间的财产与人身关系民法典、公司法
3行政法政府怎么行使权力、怎么约束政府行政处罚法、行政复议法
4经济法国家对市场经济的干预与监管反垄断法、消费者权益保护法
5社会法劳动就业、社会保障、弱势群体保护劳动法、劳动合同法、社会保险法
6刑法什么是犯罪、怎么处罚刑法
7诉讼与非诉讼程序法打官司（诉讼）与仲裁、调解的程序民事诉讼法、刑事诉讼法、行政诉讼法、仲裁法

七个部门法的划分依据，见：中国人大网 · 解读中国特色社会主义法律体系的形成和完善

4你的生活问题，住在哪栋楼？

把第一节的四个场景展开，再加上两个常见场景，做一张"生活 → 法律"对照表。这张表值得长期贴在案头：

生活场景部门法主要法律维权入口
老板拖欠工资、违法辞退社会法《劳动合同法》《劳动法》12333 人社热线 / 劳动人事争议仲裁
租房押金不退、买房纠纷、离婚、继承、民间借贷民法商法《民法典》协商 → 人民调解 → 民事诉讼
买到假货、商家欺诈经济法《消费者权益保护法》+《民法典》12315 投诉 / 市场监管部门 / 民事诉讼
被乱罚款、行政处罚不公行政法《行政处罚法》《行政复议法》行政复议 → 行政诉讼

5工具课：怎么查法条（必学技能）

法律学习最重要的不是背，而是会查。国家法律法规数据库（全国人大常委会主办）是唯一的官方权威文本库：

  1. 打开 flk.npc.gov.cn（国家法律法规数据库）；
  2. 顶部搜索框输入法律名称，如"劳动合同法"；
  3. 认准"现行有效"标签，避开已被修正或废止的版本；
  4. 点进条文页面，注意页面上的施行日期和修正历史；
  5. 核对条文时，永远以这里的原文为准，不要信搜索引擎的二手转载。

7小结

  • 中国法律是金字塔结构：宪法 → 法律 → 行政法规 → 地方性法规 → 规章；冲突时"上位法优于下位法、特别法优于一般法、新法优于旧法"。
  • 法律体系分七个部门，日常生活问题集中在民商法、社会法、经济法、行政法、刑法这五栋楼里。
  • 遇到问题先对号入座，再按"保留证据 → 协商 → 投诉/调解/仲裁 → 诉讼"推进；不确定就打 12348。
  • 所有法条以 flk.npc.gov.cn 原文为准。
